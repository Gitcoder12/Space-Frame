# Contributing to Space-Frame

1. Read README.md, FEATURE_UPGRADE_PLAN.md and ACTIVITY_LOG.md.
2. Pick one bounded visualisation, data or accessibility task.
3. Work on a feature branch.
4. Preserve scientific units and data provenance.
5. Add browser smoke tests for interaction and layout changes.
6. Do not add accuracy/live-data claims without a reference dataset and validation.
7. Open a PR with screenshots or browser/test results and limitations.
